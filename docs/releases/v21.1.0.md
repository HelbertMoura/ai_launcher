# AI Launcher v21.1.0

A security and infrastructure release. Five critical findings closed (SEC-001..005), five new Claude-compatible CLIs added (13 total), the in-app updater migrated to the official `tauri-plugin-updater`, and a vendor-chunking pass cut the main JS bundle by 57%. All dependencies brought current (`npm audit` reports zero vulnerabilities). **Zero breaking changes in the public contract.**

## Highlights

- **Security hardening**: closed SEC-001 (CVE shell injection in `open`), SEC-002 (supply-chain PR backlog drained), SEC-003 (explorer select-arg sanitization), SEC-004 (UNC path rejection in `validate_directory`), SEC-005 (documented `CRED_PERSIST_LOCAL_MACHINE` semantics).
- **Updater migration to `tauri-plugin-updater`**: legacy `self_update.rs` deleted, signature validation replaces the SHA-256 sidecar, the frontend contract (`check_app_update` / `download_verified_app_update`) is preserved. Release workflow now signs the NSIS installer with `tauri signer sign` and emits `latest.json` in the tauri-plugin-updater schema.
- **13 CLIs** now detected, installed and launched from a single surface: Claude, Codex, Qwen, Kilocode, OpenCode, Aider, Continue, Crush, Droid, Antigravity, Cody, Copilot CLI, Goose. (Gemini CLI was discontinued upstream and replaced by Antigravity; no longer in `get_cli_definitions` — see `util.rs:1339` for the regression test.)
- **Bundle -57%** (gzip): main JS chunk dropped from 92.43 kB to **41.15 kB** by splitting `react`, `i18n`, `tauri`, `dnd` and `icons` into long-lived vendor chunks. Better Tauri webview cache reuse and isolated upgrade blast-radius.
- **All deps current**: TypeScript 6 → 7, i18next 24 → 26, react-i18next 15 → 17, jsdom 29 → 30, jest-dom 6 → 7, Vite 8.2.1, Tauri 2.11.5. `@types/node` deliberately stays on 22.x (LTS).
- **CodeQL** matrix (JS/TS + Rust) added to CI on push, PR and weekly schedule. **CycloneDX SBOM** generated for both npm and Cargo on every release.
- **Marketing prep** (drafts only — not auto-published): `docs/marketing/{producthunt,dev-to,launch-checklist}.md`. Final submission is a deliberate human action.

## Operator notes

- The pubkey baked into `tauri.conf.json` under `plugins.updater.pubkey` is a freshly generated placeholder (keypair at `.tauri/ai-launcher.key`, gitignored). To make the in-app updater work end-to-end:
  1. Add the matching private key to GitHub Secrets as `TAURI_SIGNING_PRIVATE_KEY` (and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` if you keep a password on the key).
  2. Rotate the keypair if you do not trust the local `.tauri/ai-launcher.key` file.
- Without the private key in secrets, the in-app updater rejects every manifest (signing step is opt-in and skipped silently), but the manual download still works — same as the legacy `download_verified_app_update` did when GitHub blocked the API.
- 46 commits since v21.0.0, zero breaking changes in the public contract — hence MINOR (v21.1.0) instead of MAJOR (v22.0.0).
