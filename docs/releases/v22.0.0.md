# AI Launcher v22.0.0

v22 is the Multi-Agent Ecosystem & Modular Architecture release: complete modularization of the native Rust core, expanded agent ecosystem (Aider, Goose, Cline, Roo Code), 2.0 cost & budget analytics with custom time intervals, and integrated Dev Maniac's official identity and brand touchpoints.

## Highlights

- **Modular Rust Backend Architecture**: Refactored monolithic `util.rs` (1,343 lines) into co-located modules (`definitions.rs`, `process.rs`, `terminal.rs`, `versions.rs`, `tray_cfg.rs`, `mod.rs`) for cleaner boundaries, zero code duplication, and elevated testability.
- **Extended Multi-Agent Ecosystem**: Native support, stack recommendations, and custom SVG vector icons for **Aider**, **Goose**, **Cline**, and **Roo Code**, alongside Claude Code, Codex, Antigravity, and existing engines.
- **Cost & Budget Intelligence 2.0**: Interactive time-range selectors (7d, 14d, 30d, 90d) with live recalculation of daily series, project rankings, model breakdowns, and provider rollups.
- **Official Dev Maniac's Identity & Touchpoints**: Embedded author signature with secure Tauri-backed external URL handling on the Status Bar, Help/About view, Onboarding tour, and public documentation.
- **Component Decomposition**: Decoupled monolithic views in the Command Deck into isolated components (`ProjectIntelligence.tsx`, `ReadinessCard.tsx`).
- **Security & Dependency Overrides**: Zero production vulnerabilities, resolved dev-tool dependency trees, and strict validation across all Tauri IPC boundaries.
