# AI Launcher v22.7.0

The local-AI and resilience release: first-class Ollama support for running local LLMs, a deep cache cleaner with self-healing stub repair in the Doctor, and a unified MCP configuration bundle for one-click export and restore across Claude, Codex and Gemini.

## Highlights

- **Ollama Local LLM Integration**: full detection and diagnostics for the `ollama` tool (version probe via `ollama --version`, default paths `%LOCALAPPDATA%\Programs\Ollama` and `%PROGRAMFILES%\Ollama`), integrated into the concurrent Tokio health checks (`check_environment`) and tool update scans (`check_tool_updates`), with a one-click download link pointing to the official Windows installer.
- **Doctor Deep Cache Cleaning & Stub Repair**: new `cleanup_system_cache` Rust command that removes orphaned installer leftovers (`goose.zip`, `agy_install`, `ai-launcher-tmp`), npm temp folders (`.claude-code-*`) and runs preventive self-healing on executables. Exposed as a dedicated action button at the top of the Doctor page with instant feedback and a clean-environment re-diagnosis.
- **Unified MCP Configuration Bundle**: `export_all_mcp_configs` / `import_all_mcp_configs` bundle every active MCP server configuration into a single `.json` file (Claude `.mcp.json`, Codex `config.toml`, Gemini `mcp_config.json`), with automatic `.bak` backups of each configuration file before any restore, and dedicated admin cards for one-click MCP backup/restore.
