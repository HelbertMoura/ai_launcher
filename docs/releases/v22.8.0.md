# AI Launcher v22.8.0

The multi-platform release: AI Launcher now builds and ships on Windows, macOS and Linux with native secure storage per OS, a hardened Rust core with command-injection paths closed, non-blocking scans, and a 9-job public quality gate matrix running on every push.

## Highlights

- **Native Secure Storage per OS**: credential storage uses the platform-native backend — Windows Credential Manager, macOS Keychain and Linux Secret Service via the `keyring` crate — with fail-closed availability. When no secure backend is present, credential features report unavailable instead of silently degrading, and the UI gates them with explicit states.
- **Conditional Rust Core**: platform-specific process, terminal and doctor paths are conditionalized per OS, so the same core compiles cleanly on Windows, macOS and Linux with Windows-only code gated behind `cfg`.
- **Six Bundles, Three OSes**: every GitHub release now attaches msi + nsis (Windows), dmg ×2 (macOS, Apple silicon and Intel) and AppImage + deb (Linux), built by dedicated macOS and Linux bundle jobs.
- **Security hardening**: `cmd.exe` fallback metacharacters are escaped and custom command tokens are gated, closing the `cmd /K` injection gaps surfaced by the safety audit.
- **Performance**: blocking network and filesystem scans moved off the command thread via `tokio::task::spawn_blocking`; the MCP health check now performs a real HTTP reachability probe against declared servers.
- **Packaging**: official winget, scoop and chocolatey manifests with a generator script.
- **Public showcase**: new public ROADMAP (EN + pt-BR), Code of Conduct, version and quality-gates badges, multi-platform install instructions and a demo GIF recorded from the canonical workflow.

## Notes

- All operations remain 100% local, offline-first, and private. No cloud sync, telemetry, or remote tracking.
- Windows remains the first-class platform; macOS and Linux builds ship the same core with platform-native secure storage and fail-closed gating for anything not yet available outside Windows.
