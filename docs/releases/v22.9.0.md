# AI Launcher v22.9.0

The hardened-trust release: the release pipeline itself is now a security boundary — it fails closed on missing updater signatures, runs the full quality gate matrix before building any bundle, and every GitHub Actions step is pinned by commit SHA — while the webview ships under a restrictive CSP, cargo audit denies warnings, and 27 pt-BR strings regain their accents.

## Highlights

- **Fail-closed release pipeline**: the `latest.json` updater step hard-fails when `TAURI_SIGNING_PRIVATE_KEY` is not configured or when the NSIS `.sig` is absent, instead of silently publishing an unsigned manifest that the in-app updater would reject; `scripts/audit-release.sh` gained a signature-presence check.
- **Quality gates before artifacts**: the release workflow runs the full quality matrix before building any bundle, so a red gate can no longer produce installers.
- **Restrictive CSP**: production locks the webview to `'self'` plus the Tauri IPC bridge; the dev variant only additionally allows Vite HMR endpoints on localhost.
- **Pinned CI**: every GitHub Actions workflow step is pinned to a full commit SHA, eliminating tag-repoint supply-chain risk.
- **cargo audit denies warnings**: the Rust dependency audit runs with `--deny warnings`, with every ignored advisory explicitly documented in `.cargo/audit.toml`.
- **Repository infrastructure**: the SBOM backend workflow was fixed (unsupported cargo-cyclonedx flag), `.github/FUNDING.yml` enables Ko-fi, and the repository doubles as its own Scoop bucket with autoupdate.
- **pt-BR polish**: 27 UI strings missing accents fixed; backend user-facing error messages standardized to pt-BR; README claims synced with the code (7 themes, 239/127 test counts, 15 runtime checks, full CLI list including Windsurf, 3-platform positioning).

## Updater note

The release pipeline now fails closed: if the updater signing key is not configured or the generated `.sig` is missing, the workflow aborts before publishing `latest.json`. An unsigned or empty-signature manifest can no longer reach users, which protects the in-app updater from bricking itself with an update it would refuse to install.

The OTA signing key pair was also rotated for this release. The original key (generated 2026-08-10) was never provisioned into the repository secrets — the repo had zero secrets, which is why v22.8.0 shipped an empty signature. v22.9.0 ships the new public key (`612BF794E7BF518A`) and is the first release whose updater manifest is verifiably signed.

## Notes

- All operations remain 100% local, offline-first, and private. No cloud sync, telemetry, or remote tracking.
- Windows remains the first-class platform; macOS and Linux builds ship the same core with platform-native secure storage and fail-closed gating for anything not yet available outside Windows.
